# Pygame 종스크롤 슈팅게임 — 선택형 효과음 라이브러리

2인 1조 학생팀이 취향에 맞게 효과음을 골라 쓰도록 만든 교육용 샘플입니다.
모두 외부 음원 샘플 없이 파형 합성 방식으로 새로 제작한 44.1kHz / 16-bit / 모노 WAV 파일입니다.

## 시작하기

1. 압축을 풀고 `preview.html`을 브라우저로 열어 효과음을 듣습니다.
2. 원하는 효과음을 선택해 게임의 `assets/audio/sfx/` 폴더에서 사용합니다.
3. 팀 기록지에 선택한 파일명을 기록합니다.
4. `assets/audio/bgm/` 폴더는 추후 배경음악을 추가할 공간입니다. 배경음악은 포함되어 있지 않습니다.

## 폴더와 효과음 용도

- `shoot/`: 플레이어 총알 발사
- `enemy/`: 적 총알 발사
- `hit/`: 총알이 목표물에 맞음
- `explosion/`: 적 또는 보스의 폭발
- `damage/`: 플레이어 피격
- `item/`: 무기 강화·체력 회복·아이템 획득
- `ui/`: 메뉴 선택·게임 시작·일시정지·게임 오버·클리어
- `stage/`: 스테이지 전환·보스 경고·보스 등장

## 수업 운영 권장 사항

- 2인 1조가 공통 효과음 파일 중 서로 다른 것을 골라도 됩니다.
- 먼저 `shoot`, `hit`, `explosion`의 소리를 선택해 기본 게임에 적용합니다.
- 학생들이 효과음이 재생되어야 하는 상황(이벤트)을 직접 설계하도록 합니다.
- 연속 발사 소리는 지나치게 길거나 큰 소리를 선택하지 않도록 합니다.
- BGM과 효과음은 각각 볼륨을 조절할 수 있도록 게임에서 분리하는 것을 권장합니다.
- 학습용 기본 합성음이라 전문 스튜디오 제작 음원과 질감이 다를 수 있습니다.

## 저작권 및 이용

이 팩의 WAV 파일은 이번 프로젝트를 위해 새로 합성한 음원입니다.
학생 수업·학습용 게임에 자유롭게 사용하거나 수정·공유할 수 있습니다.
제3자 음원은 포함되어 있지 않습니다.

파일 목록과 길이는 `SOUND_CATALOG.csv`를 참고하세요.
